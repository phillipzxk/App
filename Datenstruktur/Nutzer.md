# Nutzer (Users)

Teil von [[Datenmodell]].

| Feld | Beschreibung |
|---|---|
| Nutzer-ID | automatisch |
| Name / Anzeigename | |
| E-Mail | |
| Registrierungsdatum | |
| Abo-Status | kostenlos / aktiv-bezahlt / gekündigt |
| Ziel | aus dem [[Kernmechanik#1. Onboarding|Onboarding]], z. B. Muskelaufbau, mehr Energie, bessere Routinen |
| Level | aus dem Onboarding: wie oft aktuell trainiert wird |
| Ausgangssituation | aus dem Onboarding: was den Nutzer gerade am meisten zurückhält (neu seit 2026-10-10) |
| Onboarding-Notiz | optional, aus dem Onboarding: Ziel in eigenen Worten (neu seit 2026-10-10) |

Mögliche Werte für Ziel, Level und Ausgangssituation: siehe [[Onboarding-Fragebogen]].

Ein Nutzer hat viele [[Check-ins]].
